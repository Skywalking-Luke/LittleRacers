# Little Racers (ages 2-5)
Gentle car games for toddlers, EN/BM. Live: https://lhcars.my/LittleRacers/
Built output at the root (GitHub Pages). Source in source/ (TypeScript + Vite): cd source && npm i && npx vite build, then copy dist/* to the root.
Voice lines: source/src/voice.ts. Recordings: add voice/<key>_<en|bm>.mp3 and list the filename in voice/manifest.json.
No ads, no external scripts, no trackers, no data collection.
